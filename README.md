# ⚡ Dumsor Tracker

A web application for tracking power outages (known as "Dumsor") in Ghana. This tool helps residents check the current power status in their region and area, view scheduled outages, and plan accordingly.

![Dumsor Tracker](https://img.shields.io/badge/Status-Active-brightgreen) 
![Version](https://img.shields.io/badge/Version-1.0.0-blue)

## 🌟 Features

- **Region Selection**: Choose from 8 major regions in Ghana
- **Area-Specific Status**: Get detailed power status for specific areas within each region
- **Real-time Status Display**: Visual indicators showing current power availability
- **Calendar View**: Monthly calendar with color-coded power status for each day
- **Today's Schedule**: Detailed hourly power schedule for the current day
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **User-Friendly Interface**: Clean, intuitive design with clear visual feedback
